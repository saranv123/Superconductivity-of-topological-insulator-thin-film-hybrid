# Results


For figures 2,3,4, differen parameters of the hybrid system is tuned and the evolution of topological superconductivity is studied. In the code, that particular parameter is tuned using a for loop, and the results are stored in a .dat file. Then, I used Wolfram Mathematica to generate plots from the data points. 

1) TI_thinfilm-sstm.png: The thin film - topological insulator hybrid system considered in this paper. Thin film is made of trivial metal, for example, lead, copper etc, while topological insulator candidates include materials like Bi2Se3, Bi2Te3, Sb2Te3 etc.. 

2) SC_gap-rsnceffct.png: Figure showing the effect of resonance between energy bands of thin film and topological insulator surface electrons. The bottom figure shows the tunneling effect, while the top one is shown for reference (before tunnling is introduced). The resonance effect can be clearly seen by the spikes in the topological superconducting order as \delta approaches zero. 

3) SC_gap-intrctnstrgth_dpndnce.png: Showed the evolution of topological superconductivity as a function of electron-electron attractive interaction strength. The system is already tuned to resonance.

4) SC_gap-frmivlcty_dpndnce: Showed the evolution of topological superconductivity on the three bands as a function of Fermi velocity of the TI surface electrons.
